Hubungkan Firebase dulu

Isi FIREBASE_CONFIG di bagian script file ini.

  1. Buka console.firebase.google.com → buat project.
  2. Build → Realtime Database → Create Database (lokasi Singapore, mode test).
  3. Tab Rules → isi {"rules":{".read":true,".write":true}} → Publish.
  4. Project settings → Your apps → Web (</>) → salin firebaseConfig (termasuk databaseURL) ke file ini.
